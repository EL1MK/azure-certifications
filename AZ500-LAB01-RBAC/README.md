# AZ-500 LAB01: Role-Based Access Control (RBAC)

## 🎯 Objective
This lab demonstrates how to manage role-based access control (RBAC) in Azure, aligned with the "Manage security controls for identity and access" module from the AZ-500 certification path.

## 📚 Context
This lab is based on the official [LAB_01_RBAC](https://github.com/MicrosoftLearning/AZ500-AzureSecurityTechnologies/blob/master/Instructions/Labs/LAB_01_RBAC.md) provided by Microsoft Learning.

## 🧪 Planned Steps
- Create multiple users in Azure Active Directory
- Create security groups
- Assign an RBAC role to the group on an Azure resource
- Bonus: enforce MFA for a particular user
