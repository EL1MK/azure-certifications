# AZ‑500 LAB10: Enabling Just‑In‑Time (JIT) Access on Virtual Machines

🎯 **Objective**

This lab focuses on enabling and configuring **Just‑In‑Time (JIT) VM access** using Microsoft Defender for Cloud.

## 📚 Context

This lab is based on the official Microsoft Learning exercise **LAB_10_Enable just‑in‑time access on VMs**.

It highlights:

- Enabling JIT VM access from Microsoft Defender for Cloud  
- Configuring allowed ports, IP ranges, and access duration  
- Requesting JIT access to a VM  
- Validating NSG rule changes during JIT access  

## 🧪 Planned Steps

1. **Prepare the Virtual Machine**
   - Deploy or identify an existing Azure VM  

2. **Enable Just‑In‑Time VM Access**
   - Activate JIT from Defender for Cloud  
   - Configure allowed ports (e.g., RDP 3389, SSH 22)  
   - Set allowed IP ranges and maximum access duration  

3. **Request JIT Access**
   - Initiate a JIT access request from the Azure portal  
   - Validate temporary NSG rules applied to the VM  
   - Connect to the VM using the approved access window
