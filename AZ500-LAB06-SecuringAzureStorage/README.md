# AZ‑500 LAB06: Securing Azure Storage

🎯 **Objective**

This lab focuses on securing Azure Storage accounts using built‑in Azure security features. It principally demonstrates how to enforce access control.

## 📚 Context

This lab is based on the official Microsoft Learning exercise **LAB_06_SecuringAzureStorage**.

It highlights:

- Deploying a Storage Account 
- Enforcing and testing secure access control  

## 🧪 Planned Steps

1. Create a service endpoint so traffic destined to Azure Storage always stays within the Azure backbone network.
2. Configure network rules so only resources from the Private subnet can access the storage account through the Service Endpoint.
3. Confirm that resources outside of the specific subnet cannot access the storage.
