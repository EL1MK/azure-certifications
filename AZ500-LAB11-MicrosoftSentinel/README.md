# AZ‑500 LAB11: Microsoft Sentinel – Deploying and Operationalizing SIEM Capabilities

🎯 **Objective**

This lab focuses on deploying **Microsoft Sentinel**, connecting data sources, creating analytics rules, and investigating security events. It demonstrates how to operationalize SIEM capabilities in Azure—aligned with the **Configure and manage threat protection** module of the AZ‑500 certification.

## 📚 Context

This lab is based on the official Microsoft Learning exercise **LAB_11_Microsoft Sentinel**.

It highlights:

- Deploying Microsoft Sentinel on a Log Analytics workspace  
- Connecting Azure sources  
- Creating analytics rules for threat detection  
- Investigating incidents and running playbooks  

## 🧪 Planned Steps

1. **Enable Microsoft Sentinel**
   - Attach Sentinel to an existing Log Analytics workspace  

2. **Connect Data Sources**
   - Enable Azure Activity logs  
   - Connect Security Events from a Windows VM  
   - Validate data ingestion  

3. **Create Analytics Rules**
   - Enable built‑in rule templates
   - Implement a custom rule
   - Configure alert thresholds and automation options  
   - Validate rule deployment  

4. **Investigate Incidents**
   - Trigger test events  
   - Review incidents in Sentinel
