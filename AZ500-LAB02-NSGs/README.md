# AZ-500 LAB02: Network Security Groups (NSGs)

## 🎯 Objective
This lab demonstrates how to configure and manage **Network Security Groups (NSGs)** in Azure, aligned with the "Implement network security" module from the AZ-500 certification path.

## 📚 Context
This lab is based on the official **LAB_02_NSGs** provided by Microsoft Learning.  
It focuses on securing Azure resources by controlling inbound and outbound traffic at the network interface and subnet level.

## 🧪 Planned Steps
1. Create a virtual network and subnet   
2. Create a Network Security Group (NSG)  
3. Define inbound and outbound security rules (e.g., allow RDP, block HTTP)
4. Deploy a virtual machine in the subnet   
5. Associate the NSG with the subnet and/or VM NIC  
6. Test connectivity to validate the applied rules
