# AZ‑500 LAB08: Log Analytics Workspace, Azure Storage & Data Collection Rule (DCR)

🎯 **Objective**

This lab focuses on creating a Log Analytics workspace, creating an Azure Storage Account, and implementing a Data Collection Rule (DCR).

## 📚 Context

This lab is based on the official Microsoft Learning exercise **LAB_08_CreateaLogAnalyticsworkspaceAzureStorageAccountDataCollectionRule(DCR)**.

It highlights:

- Deploying a Log Analytics workspace  
- Creating an Azure Storage Account
- Configuring a Data Collection Rule (DCR)  
- Connecting Azure resources to Log Analytics  
- Validating log ingestion and querying data with Kusto Query Language (KQL)  

## 🧪 Planned Steps

1. **Create a Log Analytics Workspace**
   - Deploy a workspace in the target region  
   - Review workspace settings and retention  

2. **Deploy an Azure Storage Account**
   - Create a storage account  

3. **Create a Data Collection Rule (DCR)**
   - Define data sources  
   - Configure destinations (Log Analytics workspace)
     
4. **Validate Log Ingestion**
   - Query logs using KQL in Log Analytics  
   - Confirm that data flows through the DCR
